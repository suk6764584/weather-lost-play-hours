# 날씨가 지운 운동시간 (Weather-Lost Play Hours)

공공체육시설이 폭염·한파·비로 실제로 잃는 이용시간을 국민체육진흥공단 이용 데이터로 재고,
오늘 쓸 수 있는 시간과 실내 대안(공공 실내시설·스포츠강좌이용권 강좌)을 안내하는 웹 서비스입니다.

- 서비스: https://suk6764584.github.io/weather-lost-play-hours/
- 2026년 국민체육진흥공단 공공데이터 활용 경진대회 출품작

## 데이터 출처
- 국민체육진흥공단: 공공체육시설 상세 정보, 전국체육시설 정보, 스포츠강좌이용권 등록시설·등록강좌 정보(공공데이터포털),
  기상정보활용올림픽공원이용분석정보(문화빅데이터플랫폼)
